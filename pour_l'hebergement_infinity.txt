$env = parse_ini_file(__DIR__ . '/../.env');

$host   = $env['DB_HOST'];
$dbname = $env['DB_NAME'];
$user   = $env['DB_USER'];
$pass   = $env['DB_PASS'];

try {
    $pdo = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8mb4",
        $user,
        $pass,
        [
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES   => false,
        ]
    );
} catch (PDOException $e) {
    die('Erreur de connexion à la base de données.'); // ⚠️ Ne pas afficher $e->getMessage() en prod
}

// ... getConfig + genererCodeDeblocage

3. 🚫 Désactiver l'affichage des erreurs PHP en production
En local c'est bien, en production jamais : les erreurs révèlent les chemins, la structure, parfois les mots de passe.

En haut de index.php, login.php, et tous les autres fichiers :

php
<?php
ini_set('display_errors', 0);
ini_set('display_startup_errors', 0);
error_reporting(E_ALL); // continuer à logger mais ne pas afficher
Ou mieux, dans un .htaccess à la racine :

apache
php_flag display_errors off
php_flag display_startup_errors off
php_value error_reporting "E_ALL & ~E_DEPRECATED & ~E_STRICT"
php_value log_errors on

8. 📸 Vérifier les permissions du dossier images/
Sur InfinityFree, les permissions doivent être :

text

uploads/   → 755 (si tu en as un)
Pas de 777 (dangereux et souvent refusé par l'hébergeur).

10. 🚦 Limiter les tentatives par IP (anti-DDoS)
Actuellement, tu limites par compte. Ajoute une limite par IP pour éviter qu'un bot essaie 1000 emails différents.

Table SQL :

sql
CREATE TABLE logs_connexion (
    id INT AUTO_INCREMENT PRIMARY KEY,
    ip VARCHAR(45),
    email VARCHAR(150),
    succes TINYINT(1),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_ip (ip),
    INDEX idx_date (created_at)
);
Dans login.php, avant la vérification :

php
$ip = $_SERVER['REMOTE_ADDR'];

// Compter les échecs des 15 dernières minutes
$stmt = $pdo->prepare('
    SELECT COUNT(*) FROM logs_connexion 
    WHERE ip = ? AND succes = 0 
    AND created_at > DATE_SUB(NOW(), INTERVAL 15 MINUTE)
');
$stmt->execute([$ip]);
$echecsIP = $stmt->fetchColumn();

if ($echecsIP >= 10) {
    die('Trop de tentatives depuis votre IP. Réessayez dans 15 minutes.');
}

// Après chaque tentative, loguer
$pdo->prepare('INSERT INTO logs_connexion (ip, email, succes) VALUES (?, ?, ?)')
    ->execute([$ip, $email, $connexionReussie ? 1 : 0]);
11. 🔐 Activer HTTPS (SSL gratuit)
InfinityFree fournit un SSL gratuit via Let's Encrypt. Active-le dans ton panneau → SSL Certificates.

Puis dans .htaccess :

apache
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
12. 🍪 Sécuriser les cookies de session
Dans un fichier config/session.php chargé au début :

php
<?php
if (session_status() === PHP_SESSION_NONE) {
    session_set_cookie_params([
        'lifetime' => 0,
        'path'     => '/',
        'secure'   => isset($_SERVER['HTTPS']),  // true si HTTPS
        'httponly' => true,                       // inaccessible en JS
        'samesite' => 'Strict',                   // anti-CSRF
    ]);
    session_start();
}
Puis remplace tous les session_start() par require_once 'config/session.php';.
